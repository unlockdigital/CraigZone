# Contributing

Use Node.js 22+ and Python 3.10+. Run `python3 tools/check.py` before proposing a change. Player, permission, audio and session changes should also pass `python3 tools/browser_check.py /absolute/path/to/chrome-for-testing`.

Keep a reproduction synthetic and self-contained. A short HTML fixture can describe a video/container/iframe interaction while preserving private browsing details. Report the browser version, extension version, expected behavior and observed behavior.

Preserve deliberate Play actions, selected-origin permission review, stable surviving slots, one-game audio, reversible page styles and seven-day local diagnostics. Keep diagnostics fixed-schema and bounded. Add a regression check for consequential behavior changes.

The browser controller and content scripts are shared sources. `chromium/build.py` adapts them into a Chromium Manifest V3 build. Generated build folders can be recreated from source. Icons are generated by the included Python builder; the Firefox SVG is maintained in the source tree. Browser runtimes, OpenSSL and CI actions are installed separately.
